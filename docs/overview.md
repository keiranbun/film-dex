# 1. Project Goal

- A front-end web application that shows the IMDB top 100 films and which steaming services each is available on within Australia

# 2. Target User

- This application is just for myself to test out agentic/ai workflows

# 3. Core Features

- Browse the top 100 movies according to IMDB
- The moves are sorted by rating

- Each movie is displayed in a movie card with IMDB rating & movie poster with title above it
  - If the user is the click on a movie card then the card will dim

- Everything needs to be stored within local storage with the option to export to json

# 4. Out of Scope

- Backend (This is not included in MVP as MVP is frontend only)
- API based movie fetching (We will load movies from json file that has been web scraped from IMDB)
- Storing anything in a database (For MVP a database will not be used)

# 5. Tech Stack

- React - Frontend Framework
- Vite
- [Shadcn](https://ui.shadcn.com/) - Component Library
- Tailwind - CSS Framework

# 6. Data Sources

- Top 100 IMDB Movies (data/movies.json)
