# film-dex

A frontend web app showing the top 100 movies (per TMDB) and where to stream each in Australia.

Built as a sandbox for trying out agentic AI workflows.

## Stack

- React + TypeScript + Vite
- Tailwind CSS + Shadcn
- TMDB API (data fetched once via script, committed as JSON)
